#  ID Maker

ID Maker is a simple web application that lets users create and customize fictional ID cards. Built using HTML, CSS and JavaScript.

<img width="1880" height="872" alt="Képernyőkép 2026-11-11 000533" src="https://github.com/user-attachments/assets/db1ac2f0-a4f2-4aca-8fbe-50a21c8f44a5" />

## Features

- Generate random ID numbers
- Enter a name, age, and occupation
- Upload a profile picture
- Choose between three themes: Government, Cyberpunk, and Agent
- Customize background, text, and accent colors
- Generate a QR code containing the ID information
- Download the finished ID card as a PNG image
